# Standard Video Folder Structure

Create one folder per video under the relevant series:

```text
series/<series-name>/day-001-topic-name/
├── README.md
├── summary.md
├── commands.txt
├── source-code/
├── examples/
├── practice/
├── screenshots/
├── references.md
└── resources/
```

## Notes

- Use lowercase folder names.
- Keep video folders inside the correct series.
- Add only the folders that are useful for the video, but keep the core Markdown and command files when possible.
- Keep reusable material in [../templates](../templates) or [../assets](../assets).
