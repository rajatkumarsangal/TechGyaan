# Content Guide

Use this guide when adding or updating TechGyaan learning resources.

## Folder Naming

- Use lowercase names.
- Separate words with hyphens.
- Use `day-001-topic-name` for sequential video content.
- Avoid spaces in file and folder names.

## Video README Sections

Each video README should include:

1. Video title
2. YouTube link
3. Learning objectives
4. Prerequisites
5. Commands
6. Step-by-step explanation
7. Example
8. Common mistakes
9. Practice exercise
10. Downloadable resources
11. Related videos
12. License

## Asset Placement

- Store shared images in [../assets/images](../assets/images).
- Store thumbnails in [../assets/thumbnails](../assets/thumbnails).
- Store logos in [../assets/logos](../assets/logos).
- Store banners in [../assets/banners](../assets/banners).
- Store video-specific screenshots inside that video's `screenshots/` folder.

## Linking

Use relative links for repository files so links work in forks, local clones, and GitHub previews.
