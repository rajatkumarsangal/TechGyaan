# Contributing to TechGyaan

Thanks for helping improve TechGyaan resources. This repository is organized so every video can be easy to find, learn from, and reuse.

## What You Can Contribute

- Fix typos or broken links.
- Add missing commands, examples, notes, or references.
- Improve explanations and practice exercises.
- Add resources for a new TechGyaan video.

## Content Rules

- Add new video content under the correct folder in [series](series).
- Use lowercase folder names and separate words with hyphens.
- Use the `day-001-topic-name` format for sequential video folders.
- Include the standard files listed in [templates/video-folder-structure.md](templates/video-folder-structure.md).
- Keep Markdown formatting consistent and easy to scan.
- Prefer relative links for files inside this repository.
- Store reusable assets in [assets](assets) and reusable file formats in [templates](templates).

## New Video Checklist

- [ ] Create the folder under the appropriate series.
- [ ] Add `README.md` from [templates/video-readme-template.md](templates/video-readme-template.md).
- [ ] Add `summary.md` from [templates/summary-template.md](templates/summary-template.md).
- [ ] Add `commands.txt` from [templates/commands-template.txt](templates/commands-template.txt).
- [ ] Add `references.md` from [templates/references-template.md](templates/references-template.md).
- [ ] Add `source-code/`, `examples/`, `practice/`, `screenshots/`, and `resources/` as needed.
- [ ] Update the series README.
- [ ] Update the root README if the new content should be visible from the homepage.

## Pull Requests

Keep pull requests focused. A single PR should usually cover one video, one series update, or one repository maintenance change.
