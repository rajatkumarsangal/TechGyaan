# Assets

Shared visual assets for TechGyaan resources live here.

## Folders

- [images](images) for reusable diagrams, screenshots, and illustrations.
- [thumbnails](thumbnails) for video thumbnails.
- [logos](logos) for brand and technology logos that are safe to include.
- [banners](banners) for repository, series, or video banners.

Video-specific screenshots should stay inside the related video folder.
